# SEO Audit Pro — Wiki

A desktop tool that audits **any website** for SEO, generates upload-ready
fixes, and helps you win visibility in **AI answers** (ChatGPT, Perplexity,
Google AI Overviews). It runs as a Windows GUI, a standalone `.exe`, or a
command-line tool.

> **Audit any site.** Point it at a competitor, a client, or your own site by
> URL (the SEO checks read only public pages), or load a local folder / uploaded
> files to audit and repair offline. The one exception is the **Security audit**,
> which sends benign probes and is meant only for a site you own or are
> authorized to test.

## What it does

| Area | Highlights |
|------|-----------|
| **Audit** | On-page, technical, off-page, PageSpeed / Core Web Vitals, security |
| **AI visibility (AEO/GEO)** | Prompt research + AI-answer visibility tracking over time |
| **Content creation** | FAQ pages, blog plans, full blog drafts, service pages, bulk meta descriptions |
| **Repair** | Writes a corrected, upload-ready copy of the site + verifies what got fixed |
| **Local SEO** | Generates one landing page per town from a plain-English service area |
| **Sources** | Live URL, local folder, uploaded files, or a cloned GitHub repo |
